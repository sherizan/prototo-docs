---
title: Keyboard shortcuts
description: "Reload the app and reopen the Simulator from the Prototo Terminal window."
---

These work in the Terminal window where `npx proto start` is running — not in the Claude Code window.

| Press | When to use it |
|---|---|
| **r** | Reload the app in the Simulator after something looks stuck |
| **i** | Open the Simulator if you closed it, or if it did not open automatically |

Click that Terminal window first so it is focused, then press the key. You do not type anything else — just **R** or **i**.

<Note>
**⌘R** in the Simulator records a screen video — see [Simulator](/tips/simulator). **R** in the Prototo window reloads your app. Click the right window first.

If **i** does not bring the Simulator back, make sure Xcode is installed (see [Prerequisites](/getting-started/prerequisites)). You can also run `npx proto reset` in your project folder — see [Troubleshooting](/reference/troubleshooting).
</Note>
