title: "Sharing"
description: "Send your prototype as a live link, or hand off the whole project."
---

Built a prototype you want to show someone? You have two ways to share it.

## Share a live preview

Run `proto share` and you get a link. Anyone who opens it tries the real prototype in their browser — no install, no Mac, nothing to set up on their end. This is the quick path for stakeholders, PMs, and anyone you just want to *show*.

See [Share a live preview](/sharing/share-link).

## Share via GitHub

Push the project to GitHub so someone else can clone it and run the same prototype on their own Mac. Slower to set up, but it hands over the actual files — good for engineers or teammates who want to open it in Claude Code and keep building.

See [Share via GitHub](/sharing/share-github).

---

Sharing a live preview needs a free account and has limits on how much you can share. Building prototypes locally is always free and unlimited. See [Plans and limits](/sharing/plans).
